## 5. Description
Enter Student Grades within an owned Course. The Actor-System interaction below describes implemented behavior; unimplemented extensions remain in section18.

## 6. Trigger
Teacher chooses the corresponding action in Gradebook component cell link - existing submission editor.

## 7. Preconditions
- PRE-1: Teacher is signed in, active, email verified and not suspended from teaching.
- PRE-2: The selected Course and required parent resources exist and are not deleted.
- PRE-3: Teacher owns the Course; content changes additionally require an editable Course status.
- PRE-4: An existing submitted Assignment answer is selected; numerical grading requires an explicitly configured scale.

## 8. Postconditions
**Success:** A single existing Assignment submission is graded; no parallel manual-grade record or Quiz override is created.

**Failure:** No unauthorized data is exposed or updated. Validation/conflict failures preserve existing records. Technical multi-step failure recovery/limits are described in sections11 and15; full cross-collection transactions are not implied.

## 9. Normal Flow
1. Teacher opens the Course Gradebook.
2. System authenticates the Teacher and verifies Course ownership.
3. Teacher follows Enter / Update Grade for an existing Assignment submission.
4. System opens the authorized current submission with its grading scale and revision.
5. Teacher enters a score and saves through the Assignment grading action.
6. System validates and updates the authoritative submission, then subsequent Gradebook reads reflect that result.

## 10. Alternative Flows
AF1.NF3: Student has no submission: show not_submitted and no manual-entry link. Teacher cannot fabricate a submitted answer through Gradebook; end.
AF2.NF3: Cell represents a Quiz: show the chosen submitted score read-only; end.

## 11. Exceptions
EX0.NF2: Authentication, teaching permission or ownership fails. System returns401/403 (or404 for unavailable parent resources), exposes no protected result, and ends the use case.

EX1.NF5: Invalid numerical score: follow UC-17.4 EX1.NF4 and return to the score field.
EX2.NF6: Revision conflict: follow UC-17.4 EX2.NF5 and reload submission details.
