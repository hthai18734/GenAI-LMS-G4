## 4. Actors
Primary Actor: **Teacher owning the Course**.
Secondary Actors: None; databases and storage are internal system components.

## 5. Description
View the same live course-completion result as the Student portal. Latest assessment scores, Lesson/video counts and missing requirements are shown together; no independent final-grade policy exists.

## 6. Trigger
Teacher chooses the corresponding action in TeacherGradebookPage.

## 7. Preconditions
- PRE-1: Teacher is signed in, active, email verified and not suspended from teaching.
- PRE-2: The selected Course and required parent resources exist and are not deleted.
- PRE-3: Teacher owns the Course; content changes additionally require an editable Course status.
- PRE-4: Actor supplies the required inputs listed in section13.

## 8. Postconditions
Success: Teacher sees the enrolled roster and current shared completion result. No duplicated grade records are written. Failure: ownership or data errors expose no protected results.

## 9. Normal Flow
1. Teacher opens Course Gradebook.
2. System authenticates the Teacher and verifies Course ownership.
3. System reads the paginated unique enrolled roster and accessible published activities.
4. System evaluates each Student through ProgressTrackingService and CourseCompletionPolicy.
5. System displays Lesson/video counts, latest submitted assessment scores/pass states and remaining requirements.
6. Teacher may refresh results, open an existing Assignment submission for grading or export PDF.

## 10. Alternative Flows
AF1.NF3: No enrolled students: show an empty state.
AF2.NF4: A required activity is missing/ungraded/not passed: show incomplete and list the requirement; continue NF5.
AF3.NF4: Assignment has legacy pass/revision only: show its decision without inventing a numeric score; continue NF5.

## 11. Exceptions
EX0.NF2: Authentication, teaching permission or ownership fails. System returns401/403 (or404 for unavailable parent resources), exposes no protected result, and ends the use case.

EX1.NF3: Invalid pagination: reject and return NF3.
EX2.NF4: Loading fails: display an error and allow retry/reload; no grade changes occur.

page integer1-1000000, limit1-100. Active/completed enrollments deduplicated by user ID. Latest submitted Quiz attempt/current Assignment submission only; zero differs from null. Gradebook reads use the same completion evaluator as Student progress and certificate eligibility.

- AC-2: A different Teacher and an unauthenticated user cannot perform the protected action.
